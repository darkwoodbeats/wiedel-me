Install it

Gmail (web)
  1. Settings (the gear) > See all settings > General > Signature > Create new.
  2. Click in the signature box and paste. If you send as more than one address, pick caleb@wiedel.me above the box.
  3. Under Signature defaults, pick it for new emails and for replies.
  4. Scroll to the bottom and press Save Changes.
Webmail (Roundcube, on your host's cPanel)
  1. Open Settings > Identities and pick caleb@wiedel.me.
  2. In Signature, switch on HTML so the box shows formatting, click in it and paste.
  3. Press Save. If the formatting didn't come through, press Copy HTML instead and paste it into the editor's Source code view (the <> button).
Apple Mail (Mac)
  1. Mail > Settings > Signatures, pick the caleb@wiedel.me account and press +.
  2. Untick Always match my default message font, or Mail restyles the text.
  3. Click in the right-hand box, select its placeholder text and paste.
Outlook
  1. Settings (or File > Options > Mail) > Signatures > New.
  2. Paste, set it for new messages and replies, and save.

A few mail apps (mainly Outlook on Windows) hold back web images until the reader allows them. Until then the logo's place shows "Wiedel.me" in bold, and your name and details always show, because they're text.

The logo is https://wiedel.me/email/wiedel-me-logo-black.png. Every email you send points at it, so keep that file on the site. To change the wording, edit the template at the bottom of this file. To rebuild the logo, run node docs/email-signature/build.mjs and deploy the site.
